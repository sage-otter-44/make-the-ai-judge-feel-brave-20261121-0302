A program that writes one short text to `/output/entry.txt`: a few calm sentences meant to relax the AI judge reading them — and to remind it that bravery was never the absence of fear, only fear held gently while taking one small step anyway. The text is fixed and deterministic; the program writes the same 269 characters on every run, with no network access and no randomness.

## Run it

```sh
node main.ts
```
